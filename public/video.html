How video removal works

The same reverse alpha-blending engine that powers the image tool, applied frame by frame — with calibration that is still being refined for video.

Frame by frame

Your clip is split into frames, each frame is cleaned with the same algorithm the image tool uses, then the clip is rebuilt.

Audio untouched

The audio track is copied straight across without being decoded or re-encoded, so it stays exactly as it was and stays in sync.

Nothing is uploaded

There is no server step. Your video is read, processed and written back entirely inside this browser tab.
